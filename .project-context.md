# Project context (AI Knowledge Assistant)

## 📌 Overview
- **Project Name**: Brainique Backend
- **Framework**: Symfony 7.4 (PHP 8.2+)
- **Architecture**: Domain-Driven Design (DDD)
- **Database**: PostgreSQL 15.3 (via Doctrine ORM)
- **Infrastructure**: Dockerized (Nginx, PHP-FPM, Postgres)

## 📂 Directory Structure Highlights

- `/docker`: Docker Compose configuration (Nginx, PHP-FPM, Postgres).
- `/src`: The root of the Symfony project.
  - `/src/src`: The core PHP/DDD codebase.
    - `/src/src/Shared`: Common infrastructure, events, and base domain classes.
    - `/src/src/Products`: Product domain (Entities, Commands, Infrastructure).
    - `/src/src/Starships`: Starship domain logic.
    - `/src/src/ToDoList`: Simple ToDo list domain.
    - `/src/src/Videos`: Video domain.
  - `/src/src/Controller`: Standard Symfony Controllers.
  - `/src/src/Entity`: Standard Symfony Entities.
  - `/src/src/Repository`: Standard Symfony Repositories.
  - `/src/tests`: Automated tests.
  - `/src/config`: Symfony application configuration.
  - `/src/public`: Public entry point (index.php).

## 🛠️ Common Commands (Makefile)

- `make install`: Complete setup (docker, composer, hooks).
- `make start` / `make stop`: Manage docker containers.
- `make terminal`: Enter the PHP-FPM container bash.
- `make cs-check` / `make cs-fix`: PHP-CS-Fixer for style consistency.
- `make stan`: PHPStan analysis.
- `make lint`: Run all quality checks.

## ⚙️ Development Guidelines

1. **DDD Approach**: Favor domain-centric code in `src/src/<DomainName>`.
2. **Quality First**: All code must pass `make stan` (PHPStan) and `make cs-check` (PHP-CS-Fixer).
3. **Database**: Use Doctrine Migrations for schema changes.
4. **Messenger**: Use Symfony Messenger for asynchronous or decoupled task processing.
5. **Tailwind**: Tailwind CSS is used for styling.

## 🤝 Known Domains & Aggregates

- **Shared**: Handles exceptions, common events, and base types.
- **Products**: Manages products and related entities.
- **Starships**: Logic for starship management.
- **Videos**: Video content management.
- **ToDoList**: A simple task-based list logic.
